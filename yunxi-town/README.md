# 云溪镇 · YUNXI TOWN

一座手绘等距小城镇。昼夜、四季、雨雪、居民、车辆，以及六间可以推门进入的室内。

## 运行

直接打开 `index.html` 即可。页面不需要安装依赖，也不需要联网；场景、人物、纹理、灯光和声音都由浏览器实时生成。

## 操作

- 拖拽平移，滚轮或双指缩放，点击建筑查看名片。
- 建筑名片底部有「推门进入」，可以进入面包房、咖啡馆、旧书店、公所、小学和车站的室内。
- `Space` 暂停，`N` 调整流速，`W` 切换天气，`T` 漫游，`R` 复位，`1–8` 跳转地标。
- 点击「声音」开启环境音（需要一次点击授权）。

## 关于制作

由 **DeepSeek V4.1 Flash 1017 版本**以「许愿式编程」方式生成。

纯前端实现，没有外部素材与依赖：等距场景、昼夜天气、车辆行人、室内细节与界面都由浏览器实时绘制。
