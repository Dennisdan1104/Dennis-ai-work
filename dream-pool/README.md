# 无人泳池 · THE POOL REMEMBERS

一座没有人的室内泳池。一个可以第一人称探索的梦核 / 阈限空间。

## 运行

直接双击 `index.html` 即可。页面不需要安装任何依赖，也不需要联网；所有场景、纹理、界面与声音都由浏览器实时生成。

建议佩戴耳机，并在光线较暗的环境里进入。

## 操作

| 操作 | 键位 |
| --- | --- |
| 环顾 | 按住鼠标拖动画面 |
| 移动 | `WASD` / 方向键 |
| 慢走 | `Shift` |
| 触碰 / 继续 | `E` |
| 静音 | `M` |

手机与平板：拖动画面环顾，左下摇杆移动，靠近发光物体后点击「触碰」或画面下方的提示。

## 梦境信息

你在一座闭馆后的泳池边醒来，水面上没有你的倒影。四段被池水保存的记忆散落在四周，但它们不都会回应一次按键：

- 有些东西需要你抬起头，真正地看一眼。
- 有些声音在水底，需要你走进水里接听，并安静听完。
- 有些名字藏在 17 号储物柜里。
- 有些真相，需要你站上排水口，保持不动。

集齐四段记忆后，池子尽头的红门会打开。门后没有走廊，只有另一个选择，和两种不同的结局。

大约 5 分钟。请不要背对水面。
